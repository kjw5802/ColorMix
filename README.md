# ColorMix

사진에서 색을 찍으면, 가지고 있는 도료로 그 색을 만드는 배합을 제안하는 Windows 프로그램입니다. 설치 없이 실행되고 인터넷 연결 없이 동작합니다.

## 다운로드

[Releases](https://github.com/kjw5802/ColorMix/releases/latest)에서 `ColorMix.exe`를 내려받아 새 폴더에 넣고 실행합니다.

처음 저장하면 exe와 같은 폴더에 `colormix_data.json`이 만들어집니다. 도료 목록과 작업 기록이 담긴 파일이니, exe를 옮길 때 함께 옮겨 주세요.

## 주요 기능

- **스포이드:** 사진에서 색을 찍고, 흰색이나 회색 기준으로 조명을 보정합니다.
- **배합 제안:** 보유 도료 1~3종을 섞은 배합을 색 차이(ΔE)가 작은 순서로 보여 줍니다. 브랜드를 섞은 배합과 명암 세트도 제안합니다.
- **팔레트:** 찍은 색을 모아 PNG나 PDF로 내보냅니다.
- **라이브러리:** 작업 기록을 사진 썸네일과 함께 저장하고 A4 PDF로 내보냅니다.
- **도료 관리:** 기본 도료 466종에서 보유 도료를 고르고, 사진에서 실제 색상값을 측정해 등록합니다.
- **언어:** 한국어, English, 日本語

## 알아 둘 점

- **도료 색상값은 조정이 필요할 수 있습니다.** 기본 색상값은 카탈로그나 웹에서 추출한 값이라 실제 도료의 색과 다를 수 있습니다. 가지고 있는 도료는 **도료 관리** 탭에서 색상값을 직접 고치거나, 칠한 견본을 찍은 사진에서 측정해 등록해 주세요.
- 배합 계산은 근사값입니다. 색상값을 조정한 뒤에도 실제 결과와 차이가 있을 수 있으니 항상 소량으로 시험 조색해 주세요.
- 서명되지 않은 프로그램이라 Windows 보안 경고가 나타날 수 있습니다. 스마트 앱 컨트롤이 켜진 PC에서는 실행이 차단될 수 있습니다.
- Windows 11에서 동작을 확인했습니다.

## 소스에서 실행하기

Python이 필요합니다.

```
cd colormix
pip install -r requirements.txt
python app.py
```

`colormix\build.bat`을 실행하면 `colormix\dist\ColorMix.exe`가 만들어집니다. 파일 구성과 테스트 방법, 데이터 형식은 [개발 문서](colormix/README.md)에 있습니다.
